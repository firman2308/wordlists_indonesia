# wordlists_indonesia

Collection of Indonesian birthdate wordlists formatted as `gua@DDMMYYYY1` for educational, authorized penetration testing, and security research purposes only.

Koleksi wordlist tanggal lahir format Indonesia `gua@DDMMYYYY1` khusus untuk keperluan edukasi, pengujian penetrasi legal, dan riset keamanan siber.

## 📄 Contents / Isi:
- **TTL1_A-Z.txt**: Full generated list (Teks lengkap).
- **TTL2_A-Z.zip**: Splitted compressed zip files for easier download (File pecahan format ZIP agar mudah diunduh).
